The guide's existing DM Sans and Fraunces faces are served locally to prevent
network-dependent font swaps. These Latin WOFF2 subsets were retrieved from
Google Fonts on September 29, 2026, using:

https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=Fraunces:opsz,wght@9..144,600..700&display=block&subset=latin

DM Sans supports weights 400–700; Fraunces supports 600–700 and its optical-size
axis. Both are distributed under the SIL Open Font License. Their original
license files are included alongside the fonts.
