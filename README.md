# Beckwourth Peak ride in 3D

A watercolor terrain map of [BKXC's September 25, 2026 ride](https://www.trailforks.com/ridelog/view/124349783/) at Beckwourth Peak Trails near Portola, California. It traces the actual public ridelog path, rather than the similar Park to Peak 2024 route. The page includes a route scrubber and a short playback.

**To view it:** double-click `index.html`. It is a self-contained page with the styles, app, ride path, and terrain embedded, so it also works from a `file://` URL. A network connection is useful for the optional Google fonts only.

The initial Home view is Brian's chosen framing, built into the site for every visitor. Pan, rotate, and zoom to frame the map, then open the ⚙︎ settings menu and select **Set home** to save a personal view. The ⌂ button returns to the saved view, or the site default if none is saved. **Reset default** clears a personal view and restores the site default. Personal views persist in the same browser via local storage.

The elevation profile shows the recorded altitude along the route. Hover, tap, drag, or use the arrow keys to move the ride marker and yellow track to that position. **Play ride** animates the route from the current position.

## Run

Requires Node 22.12 or newer.

```sh
npm ci
npm run dev
```

For development, open `/app.html` on the Vite server. `npm run build` regenerates the standalone root `index.html` and creates the static site in `dist/`. The checked-in data under `public/beckwourth/` makes the site work without Trailforks or elevation API requests at runtime.

## Data and attribution

- `ride.polyline` is the encoded route line from the public Trailforks ridelog map. `ride.json` contains its decoded 1,576 points draped over terrain.
- The 15.0 mile distance, 2,083 ft climb, and 2:01 moving time shown on the page are Trailforks' published ride stats. Playback position uses distance along the geometry. The terrain heights are from [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) and may differ from the ride's recorded elevation.
- `terrain.bin` and `map.json` are generated by `npm run data:ride`. The script caches source Terrarium tiles in `.cache/beckwourth/` and needs network access only when building them.
- The rendering and watercolor shaders are adapted from the [Tahoe Trails](https://github.com/kneath/tahoe-trails) fork. Its original Tahoe-specific source and documentation remain in `src/`, `scripts/`, and `docs/` for reference; the site root is the Beckwourth ride.

Use the Trailforks page for current trail information. This visualization represents one recorded ride and does not indicate current trail status or access.
